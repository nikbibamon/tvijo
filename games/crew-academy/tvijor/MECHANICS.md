# Игровой полигон Академии экипажа

[Открыть полигон](https://tvijo-crew-academy.be9ava.chatgpt.site/playground.html)

Первое задание знакомит с одним правилом. Игрок видит героя, цель и доступное действие на одном поле. После финиша кнопка «Собрать уровень 2 · 0 кредитов» создаёт следующую расстановку в браузере. Дальше уровень усложняется по одному параметру за раз. Время первого прохождения в 15–45 секунд — цель для живого теста.

| Игра | Первый уровень | Как растёт сложность | Как проверяется |
|---|---|---|---|
| Ледяной разгон · Самолётик | Нажать вправо и остановиться у маяка | Два скольжения на втором, затем больше опор, поле до 9×7 и до семи ходов в кратчайшем решении | Поиск в ширину по точкам остановки. После 48 вариантов есть запасная раскладка с нужной длиной пути |
| Световой контур · Дочка | Одним нажатием повернуть средний контакт и увидеть, как загорелась лампа | На втором уровне повёрнуты два модуля. Затем добавляются изгибы и до восьми повёрнутых модулей | Сначала строится рабочий маршрут. Связность проверяется после поворотов по тем же правилам, что на поле |
| Почта по дуге · Робот | Выбрать среднюю силу по пунктиру и отправить капсулу | На втором уровне появляется угол. С четвёртого появляется опора, а площадка становится уже | Перебор комбинаций угла и силы. Тот же расчёт определяет исход броска на поле |

## Каталог для следующих коротких игр

Первые четыре кандидата используют небольшую сетку или простую анимацию и несколько правил. Оригинальные уровни и персонажи остаются частью Академии.

| Механика | Первый игровой момент | Второй уровень и проверка |
|---|---|---|
| **Цветные ворота** | Ассистентка переводит один переключатель и проходит через створки | Два связанных переключателя. Поиск по парам «клетка и положение створок» |
| **Три команды** | Робот выполняет «шаг, шаг, взять» на коротком маршруте | Добавить поворот и обход опоры. Проверить программу симуляцией с ограничением длины |
| **Эхо на кнопках** | Самолётик повторяет два световых сигнала | Три сигнала, последовательности без таймера и повтор показа. Проверить совпадение последовательности |
| **Магнитная доставка** | Робот притягивает один груз к доку | Меняются полюса и появляется второй груз. Ограниченный перебор состояний |
| **Световые пары** | Дочка соединяет две лампы линией из клеток | Две пары с общим пространством без пересечения. Сначала строятся непересекающиеся пути |
| **Два героя, один мост** | Дочка нажимает плиту, Самолётик пролетает через открытый проход | Поменять роли и провести обоих. Поиск по двум позициям и состоянию плиты |
| **Почта по адресам** | Шпуль выбирает дом с нужным знаком | Два письма и мост с односторонним проходом. Поиск маршрута с доставкой обоих писем |
| **Тропа из зеркал** | Ассистентка поворачивает одно зеркало | Два зеркала и развилка. Симуляция луча по клеткам до приёмника |
| **Переключение гравитации** | Одним переключением доставить кубик к потолочной плите | Добавить горизонтальное скольжение и стопор. Поиск по точкам остановки |
| **Ритм состыковки** | Нажать кнопку, когда два кольца совпали. Первый допуск широкий | Два кольца с разной скоростью. Проверить окно ввода и режим без таймера |
| **Трос между опорами** | Выбрать один крепёж и прокатить капсулу к нему | Два узла, один меняет направление. Проверить достижимость обеих опор и возврата |
| **Стрелки для колонны** | Один переключатель направляет двух дронов к шлюзу | Разные маршруты и остановка перед развилкой. Симулировать всех дронов до подтверждённого финиша |
| **Ледяной конвейер** | Толкнуть контейнер до упора | Две формы грузов и разные плиты. Ограниченный поиск в ширину, отмена хода |
| **Пульс через лабиринт** | Отправить импульс и открыть соседний проход | У импульса две ветки, нужна безопасная последовательность. Провести импульс пошагово |
| **Предмет по слову** | Ввести или выбрать «трап», чтобы перейти разрыв | Два допустимых предмета и несколько способов. Словарь синонимов, список разрешённых эффектов и проверка каждого решения |

## От идеи до выпуска

1. Запиши механику, одно действие первого экрана, видимый результат, подсказку и один новый элемент для второго. Возьми своего героя и простые изображения из проекта.
2. Опиши первое поле вручную. Для второго и следующих зафиксируй входы генератора: игра, номер уровня и seed. Сохраняй seed вместе с ходами. При смене алгоритма сохраняй доступ к расстановкам прежней версии.
3. Добавь проверку, которая выполняет решение штатными игровыми командами. Ограничь перебор и оставь проходимый запасной вариант. Сложность измеряй количеством обязательных действий, шириной цели или числом новых развилок.
4. Проверь проигрыш, подсказку, отмену, повтор и возвращение после перезагрузки. Проверь клавиатуру и касание. Финиш должен показать следующее действие там же, где игрок выполнял задание.
5. Дай нескольким людям пройти первый экран без объяснений. Зафиксируй время, место остановки и нажали ли «Собрать уровень 2». Используй результаты для выбора следующей механики.
6. Сохрани в выпуске ссылку, версию генератора, проверенные seed и известные ограничения. База механик дополняется по итогам каждой игры.

В полигоне генерация бесплатна для игрока и выполняется локально. Генератор создаёт раскладку только после «Собрать уровень». Он не меняет демо-баланс и не вызывает сервис моделей. Повтор уровня использует прежнюю расстановку.
