# Проверка игрового полигона для DeepSeek

Игра на biba2: `/srv/remdesk/workspace/tvijo-crew-academy-online`.
Код этого выпуска для ревью: `/srv/remdesk/workspace/tvijo-crew-academy-online/releases/expedition-v26`.
Полный проект: репозиторий `nikbibamon/tvijo`, ветка `feat/remdesk-crew-expedition`, каталог `games/crew-academy`.
[Играть](https://tvijo-crew-academy.be9ava.chatgpt.site/playground.html) · [GitHub PR №20](https://github.com/nikbibamon/tvijo/pull/20)

На biba2 в папке выпуска лежат изменённые исходники, тест и каталог механик. Для проверки логики достаточно Node 20 и файлов выпуска:

```bash
cd /srv/remdesk/workspace/tvijo-crew-academy-online/releases/expedition-v26
node --test tests/playground.test.mjs
```

Цель: в каждой игре новичок быстро проходит первый уровень, нажимает «Собрать уровень 2 · 0 кредитов», получает проходимую расстановку и возвращается на то же поле после перезагрузки.

1. Прочитай `tvijor/MECHANICS.md` и `web/playground/levels.js`. Проследи путь от финиша до сохранения нового seed. Сверь, что повторное нажатие с предыдущего уровня не двигает прогресс второй раз.
2. Проверь генерируемые уровни через `tests/playground.test.mjs`. В «Воздушном обходе» пройди к потолочному переключателю и нырни через люк под настил. Проверь, что пеший герой остаётся на настиле и при подлёте шлюз ещё закрыт до нажатия. Приведи игру, номер уровня, seed, команды и ожидаемый результат для каждого подтверждённого случая.
3. Посмотри первые задания с точки зрения игрока. Укажи до трёх конкретных улучшений. Выбери две новые механики из каталога или предложи свои, с одним действием для первого уровня и способом проверить второй.

Результат ревью — короткий отчёт. Ревью работает по коду и бесплатным локальным тестам. Деплой и изменение игровых данных в задачу не входят.
