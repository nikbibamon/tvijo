# Воспроизводимая сборка · 1.0

Начинай со свежего рабочего дерева ветки разработки. Выполни `python3 tvijor/run.py run verify` из корня игры. В отчёте сверь отпечаток исходников, графику, маршруты, тесты, собранный Worker и HTTP-ответы встроенного обработчика. Различай запуск на ВМ, проверку staging через HTTPS, устройство реального игрока и доступную публикуемую ссылку. В журнале укажи, для какой ревизии получено каждое свидетельство.

Для biba2 используй копию кандидата через Git или проверенный пакет RemDesk. В актуальном Worker станция хранит данные в D1. Для полноценного бэкенда на ВМ потребуется постоянное хранилище социальных API. FastAPI уже обслуживает команды, пилотную аналитику и отчёт. Проверь две разные игровые сессии, сохранение данных при перезапуске, миграции, основной портал и возможность возврата к принятому релизу. Реальные семейные расходы проходят отдельное согласованное испытание с тарифом, лимитом, идемпотентностью и сверкой квитанций.
